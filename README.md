# Calculator App

A simple GUI calculator built with Python and tkinter.

## Requirements

- Python 3.x
- tkinter (included in the standard Python distribution)

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/eliu105/testproject
   cd testproject
   ```

2. Verify Python 3 is installed:
   ```bash
   python3 --version
   ```

No additional dependencies are required.

## Usage

Run the calculator:

```bash
python3 calculator.py
```

## Running Tests

```bash
python3 -m unittest test_calculator.py -v
```
